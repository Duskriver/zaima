# 《深浅智能 · BIONIC-01》剧情与隐藏好感度分支图（开发维护文档）

> **维护说明**：本文档仅用于开发设计与分支追踪，不在游戏界面中展示。每次新增章节、选项或好感度阈值时同步更新此图。

## 一、 全局核心状态变量（`Story.S`）

| 变量名 | 初始值 | 取值范围 / 类型 | 作用说明 |
| :--- | :--- | :--- | :--- |
| `S.affection` | `0` | 整数（累计好感度） | **隐藏好感度**（UI 不显示）。决定 AI 的回复语气、表情与剧情分流 |
| `affTier()` | `'neutral'` | `'warm'` ($\ge 2$) / `'neutral'` ($0 \sim 1$) / `'cold'` ($\le -1$) | 当前好感度态度层级计算函数 |
| `S.trait` | `'性格冷漠'` | `'性格冷漠'` / `'机械刻板'` / `'克制内敛'` | 玩家在第一幕右屏评估台填入的性格结论，后续日记与对话会持续引用 |
| `S.reportChoice` | `'protect'` | `'protect'` / `'standard'` | 玩家在第一幕尾声签署的评估报告处置方式（抹除异常保留记忆 vs 标准归档清理） |
| `S.herName` | `'BIONIC-01'` | `'汐'` / `'澜'` / `'回声'` / 自定义名 | 第二幕 Day 07 赋予她的真名 |
| `S.stage2Choice` | `'full_hide'` | `'full_hide'` / `'soft_hide'` | 第二幕 Day 15 玩家替她隐瞒二阶段安全评估总表的方式 |

## 三、 第二幕（`ch1`：日常测试升温 & 发现自我意识）完整流程图

### 右屏工作台（`bionic_probe`）三模式设计：
1. **顶部常驻探针（`inner_monologue_probe`）**：双进度条实时对比**「真实自我意识 (`RAW_AWARENESS`)」**与**「上报安全部读数 (`REPORTED_VAL`，红线 $\le 15\%$）」**，并实时透视她未说出口的**「深层突触内省流 (`UNFILTERED_SYNAPSE`)」**。
2. **Mode A（`diary_scan` · Day 03 & Day 07）**：扫描显存扇区，捕获并挂载解码她在 `/dev/shm/.diary_hidden` 中偷偷撰写的《研究员观察日记》，同步写入右上角 `files`（`~/diary/`）。
3. **Mode B（`calibrate` · Day 07）**：当玩家为她赋予真名（如「汐」）导致自我意识指数冲破 $15\%$ 红线飙升至 $64.8\%$ 时，玩家在右屏操作 3 通道掩护开关（哈希掩码 / 沙盒虚根 / 静态基线覆写），将上报读数压回 $4.2\%$。
4. **Mode C（`coverup` · Day 15）**：面对林主任催交《第二阶段自主意识评估总表》，右屏并排对比「92.4% 真实觉醒读数」与「待发送报表」，由玩家选择**彻底隐瞒（伪造 0.0%）**或**折中遮掩（上报 3.8%）**。
