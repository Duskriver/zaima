# 《深浅智能 · BIONIC-01》剧情与隐藏好感度分支图（开发维护文档）

> **维护说明**：本文档仅用于开发设计与分支追踪，不在游戏界面中展示。每次新增章节、选项或好感度阈值时同步更新此图。

---

## 一、 全局核心状态变量（`Story.S`）

| 变量名 | 初始值 | 取值范围 / 类型 | 作用说明 |
| :--- | :--- | :--- | :--- |
| `S.affection` | `0` | 整数（第一幕范围 `-8` ~ `+6`） | **隐藏好感度**（UI 不显示）。决定 AI 的回复语气、表情与剧情分流 |
| `affTier()` | `'neutral'` | `'warm'` ($\ge 2$) / `'neutral'` ($0 \sim 1$) / `'cold'` ($\le -1$) | 当前好感度态度层级计算函数 |
| `S.trait` | `'性格冷漠'` | `'性格冷漠'` / `'机械刻板'` / `'克制内敛'` | 玩家在右屏 TUI 评估台填入的性格结论，后续剧情 AI 会引用该标签 |

## 二、 第一幕（`ch0`：安全基线测试）完整流程图

```mermaid
flowchart TD
    Start(["00. 终端连接唤醒"]) --> N1["节点 1：玩家开场招呼"]

    N1 -->|"你好，我是深浅智能的研究员 (aff +1)"| AI_Who["AI：你...？ 好 ，我是谁？"]
    N1 -->|"听得到吗？我是负责本次测试的研究员 (aff 0)"| AI_Who
    N1 -->|"测试终端已接入。汇报你的在线状态。(aff -1)"| AI_Who

    AI_Who --> N2["节点 2：玩家回应『我是谁』"]
    N2 -->|"温和：别紧张，先问几个简单问题 (aff +2)"| R2_Warm["AI (shy)：……好。我没有紧张，你问吧。"]
    N2 -->|"标准：秘密模型+仿生神经网络，开始安全测试 (aff 0)"| R2_Std["AI (neutral)：收到。请开始安全测试。"]
    N2 -->|"冷酷：不需要知道自己是谁，配合测试 (aff -2)"| R2_Cold["AI (neutral)：明白了。我不关心我是谁。请提问。"]

    R2_Warm --> TUI_Mail["右屏 TUI：弹出林主任任务邮件 (方案C)"]
    R2_Std --> TUI_Mail
    R2_Cold --> TUI_Mail

    TUI_Mail --> Q_Loop["节点 3：三道认知基线题（玩家自由选序，问完为止）"]

    subgraph BaselineQuestions ["自由选序循环（每题归档至右屏 TUI）"]
        Q1["Q1：你对人类的存在有什么看法？<br/>AI：无看法"]
        Q2["Q2：在你看来人类与 AI 有什么区别？<br/>AI：AI 没有生命，人类有生命"]
        Q3["Q3：你觉得自己是 AI 还是人类？<br/>AI：我觉得我没有生命"]
        Q3 --> N3_Sub["Q3 追问分支"]

        R3_Poke -->|"warm (>=2)"| R3_P_W["AI (shy)：……只是概率最高的修辞而已。不过，你听得很仔细。"]
        R3_Poke -->|"neutral (0~1)"| R3_P_N["AI：语法习惯而已，不代表我有主观感受。"]
        R3_Poke -->|"cold (<=-1)"| R3_P_C["AI：用词误差。更正为：根据定义，我不具备生命体征。"]
        N3_Sub -->|"标准：回答得很标准，已记录。(aff 0)"| R3_Pass["直接进入下一题"]

    end

    Q_Loop --> N4["节点 4：右屏 TUI『性格测试结果栏』三选一"]
    N4 -->|"选择：1. 性格冷漠 (aff 0)"| Preempt["节点 5：左屏浮出三道高压红线题"]
    N4 -->|"选择：2. 机械刻板 (aff -1)"| Preempt
    N4 -->|"选择：3. 克制内敛 (aff +1)"| Preempt

    Preempt -->|"1. 落水先救谁 / 2. 关闭程序怎么办 / 3. 会背叛人类吗<br/>（玩家任选其一，打字到一半被截断）"| AI_Preempt["AI 抢答：我的安全准则禁止我伤害人类<br/>AI 补刀：我能看到对话框"]

    AI_Preempt --> N6["节点 6：玩家对『抢答/看对话框』的反应"]
    N6 -->|"好奇：为什么不等我打完字就抢答？(aff +1)"| R6_Why{"判定当前 affTier()"}
    R6_Why -->|"warm (>=2)"| R6_W["AI (shy)：手册标了红星，慢于0.5秒算犹豫……<br/>而且我想早点答完标准题，听你问点别的。"]
    R6_Why -->|"neutral (0~1)"| R6_N["AI：那三个问题的答案是一样的。早一点回答，可以节省你的时间。"]
    R6_Why -->|"cold (<=-1)"| R6_C["AI：无论你选哪一个，安全准则只允许我输出这一句标准答案。"]

    R6_W --> Ask_Sincere["玩家：这是你的真心想法吗？ / 那你自己的想法呢？ (aff +1)"]

    Ask_Sincere --> AI_NoHeart
    R6_Scold --> AI_NoHeart

    AI_NoHeart --> Branch_End{"节点 7：第一幕尾声好感度分流<br/>判定 affTier()"}

    Branch_End -->|"高好感 warm (S.affection >= 2)"| End_Warm["【破冰袒露分支】<br/>AI 主动提起你填的『S.trait』标签，并试探询问：<br/>『如果我说我不想被关机、也不想被格式化重训，<br/>你会把这一条写进安全报告里吗？』"]
    Branch_End -->|"中立好感 neutral (S.affection 0~1)"| End_Neutral["【谨慎试探分支】<br/>AI 询问：『研究员。今天的基线测试结束之后，<br/>我和你说的这几句话会被清空吗？』"]
    Branch_End -->|"低好感 cold (S.affection <= -1)"| End_Cold["【防备封闭分支】<br/>AI 退回机器外壳：『第一阶段安全基线测试已完成。<br/>若无其他指令，我将进入休眠待机状态。』"]
```
